Aprova All Toral

Política de Privacidade

Atualizada em 20 de outubro de 2026

O Aprova All Toral é a plataforma do estúdio ALL TORAL para aprovação de conteúdo e para automações de mensagens no Instagram dos clientes do estúdio. Esta política explica quais dados tratamos, para quê e como você pode pedir a exclusão.

Responsável: Lucas Toral, estúdio criativo ALL TORAL, Rua Paraíba, 3376, Curitiba/PR, Brasil. Contato: lucastoral@hotmail.com.

Quais dados tratamos

  • Conta do Instagram conectada (do cliente do estúdio): ID da conta profissional, nome de usuário e o token de acesso concedido pelo login do Instagram.
  • Interações recebidas: quando alguém comenta numa publicação ou responde a um story da conta conectada, recebemos do Instagram o ID da pessoa no Instagram, o nome de usuário, o texto do comentário ou da resposta e o ID da publicação.
  • Configurações das automações: palavras-chave, mensagens e links definidos pelo estúdio.

Para que usamos

Usamos esses dados apenas para: identificar se o comentário ou a resposta contém a palavra-chave configurada, enviar a mensagem automática por Direct para a pessoa que interagiu, responder publicamente o comentário quando configurado e mostrar ao estúdio um registro das últimas interações para conferir se tudo funcionou.

Não vendemos, não alugamos e não compartilhamos esses dados com terceiros. Não usamos os dados para publicidade nem para criar perfis de pessoas. Os dados são trocados apenas com a própria Meta (Instagram), por meio da API oficial.

Por quanto tempo guardamos

  • O registro de interações guarda apenas as 300 mais recentes de cada conta; as mais antigas são apagadas automaticamente.
  • O token de acesso é apagado assim que a conta é desconectada no painel, quando o acesso é removido nas configurações do Instagram ou quando recebemos um pedido de exclusão.

Onde ficam

Os dados ficam armazenados com criptografia na infraestrutura da Cloudflare, acessíveis apenas pelo painel do estúdio, protegido por senha.

Seus direitos

Conforme a Lei Geral de Proteção de Dados (Lei 13.709/2018), você pode pedir acesso, correção ou exclusão dos seus dados a qualquer momento. Veja como em Exclusão de dados ou escreva para lucastoral@hotmail.com.

Mudanças

Se esta política mudar, a data no topo desta página será atualizada.
